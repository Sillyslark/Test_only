Card Text 是 WS 官方 Card Information 之一，用于表示印刷在卡片上的规则文本。

本节仅保留 Card Text 在基础 JSON 存储章节中的位置，不在这里定义其具体 JSON 结构。

Card Text 在模拟器中的结构化表示、Ability / Effect 的关系、ACT / AUTO / CONT 的程序实现方式，以及是否需要保存官方原文文本等问题，统一在第 2.4 节定义。

> 详见：[2.4 Card Text / Ability](../04_card_text_ability/README.md)
