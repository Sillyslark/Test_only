本节仅保留 Card Number 在基础 JSON 存储章节中的位置，不在这里定义其具体 JSON 结构。

Card Number 的结构化表示、字段组成、Base Card Number / Full Card Number 的关系，以及其在模拟器中的存储与索引方式，统一在第 2.3 节定义。
