本节定义 Card JSON 中保存的 Base Card Number 数据结构及其各组成字段的职责。

Card JSON 始终只保存 Base Card Number 对应的结构化数据。Variant 虽然存在于完整 Card Number 体系中，但不属于本节规定的基础 Card JSON 存储内容，其具体处理留待后续 Index / Variant 相关章节定义。
