## 2.8 卡片稳定身份

**类别：稳定标识**

对局中每一张 `Card` 必须能够被稳定引用。

该标识会用于：

- Action
- Choice
- GameEvent
- Replay
- 状态比较
- 调试

第一节规定稳定标识原则上使用：

```python
..._id
```

因此卡片稳定标识的规范候选为：

```python
card_id
```

当前代码使用：

```python
instance_id
```

这里暂时不立即决定迁移，因为 `instance_id` 已经广泛参与现有操作、测试和 Replay。

必须区分：

```text
card_id
→ 本局中的某一张具体卡

card_number
→ CardDefinition 上的 Card Number
```

例如：

```text
CardDefinition.card_number = "T-001"

Card.card_id = "P1-T001-03"
```

前者回答“这是什么卡”，后者回答“这是本局里的哪一张卡”。
