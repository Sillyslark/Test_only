# WS Simulator 命名规范

本目录用于统一 WS Simulator 中的规则概念、程序对象、变量以及 UI 名称。

命名规范采用分节文档管理。进行任何命名设计或迁移时，应先阅读总则，再阅读对应领域的规范文档。

## 文档目录

1. [命名类别与基本原则](01_general.md)

后续章节将在内容确认后依次加入。

## 使用原则

- `01_general.md` 是所有命名工作的共同基础。
- 各领域的具体命名规则分别保存在对应章节文件中。
- 新增或修改命名前，应先确认概念所属类别。
- 官方规则已有明确术语时，原则上优先采用官方术语。
- 项目概念与官方术语发生冲突时，应优先保留官方术语，并为项目概念增加明确限定词。
- 现有代码是否迁移以及如何迁移，在各领域规范确认后再统一处理。
